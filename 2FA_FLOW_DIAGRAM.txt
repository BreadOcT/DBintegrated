┌─────────────────────────────────────────────────────────────────────────────┐
│ API ENDPOINTS                                                                │
└─────────────────────────────────────────────────────────────────────────────┘

POST /api/auth/2fa/generate
  Input:  { method: 'authenticator' | 'email' | 'sms' }
  Output: { qrCode, secret, message } atau { message, method }
  Auth:   Token Required

POST /api/auth/2fa/verify-setup
  Input:  { code: string, method: string }
  Output: { message, backupCodes: string[] }
  Auth:   Token Required

POST /api/auth/2fa/disable
  Input:  { password: string }
  Output: { message }
  Auth:   Token Required

POST /api/auth/2fa/status
  Input:  { enabled: boolean }
  Output: { message }
  Auth:   Token Required

┌─────────────────────────────────────────────────────────────────────────────┐
│ SECURITY LAYERS                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

Layer 1: Password Auth
   └─► Verifikasi email & password

Layer 2: 2FA Verification
   ├─► TOTP (Time-based OTP) dari Authenticator
   ├─► Email OTP
   └─► SMS OTP

Layer 3: Backup Codes
   └─► Emergency access jika metode utama hilang

Layer 4: Disable Protection
   └─► Require password untuk nonaktifkan 2FA

Layer 5: Audit Log (Future)
   └─► Track semua aktivitas 2FA
